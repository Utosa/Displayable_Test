# Displayable 技术复盘视频 · 极简提词卡（配 150 行原版 script.rpy）

> 录法照旧：**不背词、不卡秒表**。代码本身就 4 步，在游戏里一路点下去就是提纲；嘴瓢就原地停 1 秒重念那一句，后期一剪刀剪掉。

## 第 1 块：一句话讲清 `Displayable` + `CustomBox`（约 40 秒）

- **画面**：左边 VS Code 停在 `CustomBox` 那二十来行，右边游戏画面正停在第一步蓝色方块。
- **提词**：
  - 「平时写 Ren'Py 放立绘按钮用 `screen` 就够了，但要做血条、小游戏、长按蓄力这种自己带状态的控件，就得继承 `renpy.Displayable`。」
  - 「看这个最简单的画色块类，记住四个词就行：」
  - 「大写 `renpy.Render` 是找引擎领一张空白画板；小写 `renpy.render()` 是把子组件现场画成一张小画片；`rv.blit` 就是把小画片贴到大画板上；底下 `visit` 是把子组件清单报备给引擎，方便它预加载和管内存。」
  - 「顺手提一句 `st` 和 `at`：`st` 是当前组件显示了几秒，`at` 是动画总时间——比如艾琳开心三秒后变生气，表情换了 `st` 就归零，但艾琳人还在场上，`at` 就接着三秒继续跑。」

*(闭麦停 2 秒)*

## 第 2 块：`_SpaceHoldAdvance`——`redraw`、`timeout`、`return True`（约 50 秒）

- **画面**：游戏点到第二步，演示按住空格 1 秒绿条长满跳到下一句；VS Code 切到 `_SpaceHoldAdvance`。
- **提词**：
  - 「接着看怎么用 `Displayable` 做长按空格推进对话。前面就是记状态：按下空格记录 `is_holding` 和按下的 `st`，松开归零。」
  - 「重点是底下这三样：」
  - 「**`renpy.redraw(self, 0)`**：Ren'Py 平时很懒，画面不动就不重画；调这句就是叫引擎『下一帧重调一次 `render()`』，所以绿条才会一帧帧变长。」
  - 「**`renpy.timeout(0.01)`**：记住 **`redraw` 只叫醒 `render` 画画，不会叫醒 `event` 算逻辑**！如果玩家一直按住空格、鼠标一动不动，不加 `timeout`，`event()` 就没人叫醒去检查 1 秒到了没。写上 `timeout(0.01)` 等于让引擎每 0.01 秒塞个定时事件进来敲门。」
  - 「**`return True` vs `return None`**：时间没满前返回 `None`，意思是不结束交互继续等；只要在 `event()` 里 **返回任何非 `None` 的值（比如 `True`）**，当前交互就当场结束了——放对话里就是直接过到下一句，而且交互都结束了自然也不用再 `redraw`。」

*(闭麦停 2 秒)*

## 第 3 块：`SpaceHoldButton` + 一个实战小坑 & 收尾（约 35 秒）

- **画面**：游戏按第三、四步（长按弹 `Notify`，再长按触发 `Jump` 跳进 `done_label`）；VS Code 滑到 `SpaceHoldButton`。
- **提词**：
  - 「最后加个 `action` 参数，时间满了调 **`renpy.run(self.action)`**，就能接 Ren'Py 的 `Notify`、`Jump` 这些标准动作。」
  - 「顺便补个实操小坑：如果是 `Notify` 或 `Show` 这种**返回 `None`、不会退出当前画面**的 Action，在 `renpy.run` 前记得补一句 **`renpy.redraw(self, 0)`**，不然绿条会僵在满格消不掉。」
